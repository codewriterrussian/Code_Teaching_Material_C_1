# C Programming Teaching Materials

This repository contains **C-language teaching materials only**. It is maintained
independently from `Code_Teaching_Material_3` and does not include the C++ or
Python curricula.

## Materials

- `student_handouts_md/C/`: C lessons, Markdown handouts, examples and images.
- Other C-specific folders (if present) preserve the source organization.
- C-related root handouts from the original teaching folder are retained as needed.

The initial material selection includes 422 Markdown-handout-area files.

## Privacy and publishing

Local teacher-only notebooks, solutions, private notes, original archives and
working tools are excluded from Git tracking. Review `git status` before each push.
